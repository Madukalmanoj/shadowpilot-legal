# ShadowPilot - Real-Time AI Assistant

**Official Public Homepage & Documentation**

ShadowPilot is an intelligent, real-time desktop assistant designed for interviews, meetings, and contextual productivity.

---

## 🔒 Security & Privacy Commitments
- **Google OAuth 2.0 Integration**: Used exclusively for user authentication and managing session entitlements.
- **Minimal Data Access**: We only request `openid`, `email`, and `profile` scopes to verify your account identity.
- **No Third-Party Data Selling**: Your account details and transcriptions are never sold, rented, or shared with advertisers.
- **Google API User Data Policy**: ShadowPilot strictly adheres to Google's Limited Use requirements.
